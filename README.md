# ASM — 8086 Assembly Lab Programs

Assembly language programs for the BSc lab exam: arithmetic, input/output, arrays, loops, jumps and conditions.

## Run

Open any `.asm` file in the [emu8086](http://www.emu8086.com/) emulator, then **Compile & Emulate**.

## What's inside

| Files | Topic |
|-------|-------|
| `addTwoNum.asm`, `addSubMulDiv.asm`, `multiplication.asm`, `DivisionCalculator.asm`, `subTwoNum.asm` | Arithmetic |
| `array.asm`, `arrayCounter.asm`, `InputInArray&Display.asm` | Arrays |
| `loopConcept.asm`, `LoopPrintMultipleTime.asm` | Loops |
| `jmpConcept.asm`, `compareNumbrJMP.asm`, `CompareThreeNum.asm` | Jumps & conditions |
| `sumByFunction.asm`, `Function and string concept.asm` | Procedures & strings |
| `sound beep.asm`, `printHello.asm`, `Taking simple input.asm` | I/O basics |

`Program_List_21.pdf` and `emu8086_programs_Q3_Q10.docx` are the lab program list and notes.
